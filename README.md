# Love From Zero · 零经验恋爱起始指南

> 面向母胎单身、从未谈过恋爱的异性恋男性——从认识自己开始，到确认关系结束。不是"教你追人"，是"让你成为一个知道自己在做什么的人"。

很多恋爱教程只会说"勇敢去追"或"做自己就好"。Love From Zero 试图做得更认真一点：它是一套**有诊断、有判断依据、有退出机制**的渐进式路径，不是一本话术抄。

它不是要你变成另一个人。它要你搞清楚自己是谁、你想要谁、然后——别搞砸。

> **注意：本 skill 明确面向异性恋男性用户。** 如果你不是这个群体，请使用通用版本的 [狗头军师 (Goutoujunshi)](https://github.com/powerycy/goutoujunshi)，它支持多元性取向和性别身份。

## 它能做什么

- **从零开始，完整路径**：六阶段渐进式路径——准备期 → 观察侦察 → 破冰 → 连接升温 → 暧昧澄清 → 关系建立。不跳步，不省略。
- **认识自己先于追人**：在接触任何人之前，先厘清你的性格倾向、沟通风格、情绪模式和真实需求。区分"我真的喜欢她"和"我只是不习惯有人靠近我"。
- **预评估矩阵（主客观交叉验证）**：接触前先用可观察的客观事实评估接触可能性、破冰难度和共同话题池，不做没有数据的决策。
- **双轨趋势监测**：不让你自己数数据——你只需要贴聊天记录给 skill，skill 提取量化指标和内容分析，告诉你信号是向上还是向下。
- **假阳性过滤器（五维交叉）**：区分"她对你变熟了"和"她对你有意思"——零经验者最容易把朋友信号误读为好感，这个过滤器帮你按住刹车。
- **首次邀约策略**：别问"有空吗"。告知+给选择，二选一封闭式。第一次见面怎么安排、被拒了怎么回，全都写好了。
- **信号识别矩阵**：从主动联系、特别对待、记得细节等七个维度判断信号可靠性，用星级标注，不靠脑补。
- **期待校准**：在进入暧昧期前，强制问自己——我是不是在投射幻想？我见过她不高兴的样子吗？
- **弹性告白拷问流（grill-me 模式）**：不给你模板话术。一次问一个问题，根据你的回答决定下一问，从"兴奋还是紧张"开始分叉到素材收集或期待校准支线。直到你自己说出真心话。
- **关系健康度评估（随时可触发）**：没进展？不知道要不要继续？skill 引导你做冷静评估，分三档建议——继续推进 / 降低期待 / 退出。
- **人品实时红线（全阶段并行）**：对服务员无礼？频繁放鸽子？不接受你说"不"？独立于好感信号，随时亮灯。好感再高，一条红线也照亮。
- **内置完整知识库**：20 篇关系心理学知识文档 + 21 份实操指南。覆盖接话、夸人、情绪价值、冲突修复、话题金字塔、依恋理论、MBTI、PUA 识别与伦理替代等。
- **按需加载，不浪费 token**：默认只加载当前问题直接需要的 1-3 份参考。不会一次性把整个知识库塞进上下文。

## 为什么不用直接看 PUA 教程？

因为 PUA 教你怎么"得到一个人"。Love From Zero 教你怎么**不失去自己**。

| 维度 | PUA 教程 | Love From Zero |
|------|---------|---------------|
| 核心假设 | 对方是目标，关系是游戏 | 对方是人，关系是双向选择 |
| 失败处理 | 技巧不够，继续练 | 体面退场，保留骄傲 |
| 心态起点 | 你不够好，所以需要技巧 | 你本来就够好，只是没有经验 |
| 信号判断 | 她回应了就是对你有意思 | 量化+内容+假阳性过滤，做好人不好感 |

## 安装

### Codex (OpenAI Agents) 版本

```bash
git clone https://github.com/ATP-ADP/XiaoChunan-love-from-zero.git
# 然后复制 codex/ 目录到你的 Skills 目录
cp -r codex ~/.codex/skills/love-from-zero
```

在 Codex 中输入：
```text
使用 $love-from-zero 帮我从零开始，梳理我的恋爱观念并给出下一步建议。
```

### WorkBuddy 版本

```bash
git clone https://github.com/ATP-ADP/XiaoChunan-love-from-zero.git
# 然后复制 workbuddy/ 目录到 WorkBuddy Skills 目录
cp -r workbuddy ~/.workbuddy/skills/love-from-zero
```

WorkBuddy 在重启对话后会自动发现技能列表中的 `love-from-zero`。

### 首次使用

技能第一次被激活时，它会先问你一个开放式问题：

> "你现在是什么情况——是没有目标想了解怎么开始，还是已经有喜欢的人不知道怎么推进？"

根据你的回答，它会从对应的阶段开始引导你。

## 一个典型回答如何产生

```text
用户叙述（或贴聊天记录）
  → 模式判定（零经验空白 / 有目标困惑 / 紧急例外）
  → 加载当前阶段引导
  → 分析用户提供的原始素材（skill 提取量化+内容，非用户自行统计）
  → 给出选项而非替代决定（给选项/若不确定则拷问/严禁诱导话术）
  → skill 给判断 + 用户确认权（"你觉得这个判断准确吗？"）
  → 生成行动、观察窗口、下一阶段突破条件
```

## 设计原则

1. **先接住人，再解决事。** 零经验者的焦虑和犹豫不是需要绕过的障碍，是需要被承认的起点。
2. **给选项，不吃定主意。** 用户说"不确定"时进入拷问找到真心话，严禁诱导话术。
3. **行为比标签可靠。** 不凭 MBTI、星座或一次聊天判定对方。
4. **互惠比追到更重要。** 得到一个人不是唯一胜利；减少内耗、保留尊严与未来选择权同样是成功。
5. **体面退场比死缠烂打重要。** 被拒绝后的反应，比你被拒绝这件事更能定义你。
6. **同意和退出权不可绕过。** 明确拒绝不是需要破解的障碍。
7. **关系不是对自我价值的验证。** 被一个人拒绝 ≠ 你不够好。可能只是时机、适配度或对方状态不对。
8. **危险情境先保安全。** 暴力、胁迫、跟踪、诈骗和自伤风险不能用普通恋爱话术处理。
